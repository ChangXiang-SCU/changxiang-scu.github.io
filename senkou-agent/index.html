Senkou Agent: A Local LaTeX IDE with AI Assistants

Xiang Chang
Open-source tool · 2026
Code Documentation
Figure placeholderstatic/teaser.png

Source, live PDF and an AI assistant side by side, running on your own machine.

Overview

Senkou Agent is a LaTeX IDE that runs on your own machine. It combines a CodeMirror editor, live PDF preview, an AI assistant that can use Claude, OpenAI, Gemini or OpenRouter, Overleaf-style comments, GitHub and Overleaf sync, and Canvas assignment import.

Each paper is a folder under one projects directory. Besides the editor there are dashboard, calendar and library pages, and the calendar can read a Canvas calendar feed for deadlines.

How It Works

Write, compile, ask and sync without leaving one local app.

Local by design

The server listens on 127.0.0.1 only, other websites cannot call its local API, and secret files are never served. API keys and tokens live in a git-ignored config.json. The server has no login, so it should not be exposed to an untrusted network.

Requirements

  • Node.js 20.19 or newer (22 LTS recommended)
  • A TeX distribution with xelatex, pdflatex and bibtex: MiKTeX, MacTeX or TeX Live
  • Git, for updates and for GitHub and Overleaf sync

Based on SwiftLaTeX (AGPL-3.0).
